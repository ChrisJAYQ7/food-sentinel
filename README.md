# BACTERIO Terrain EFSA

Application de terrain (100% hors ligne) pour le Générateur de Planning BACTERIO avec intégration **EFSA FoodEx2** et scanner intelligent.

- **URL de déploiement :** https://chrisjayq7.github.io/food-sentinel/ (ou votre nouveau repository)
- **Décodage GS1 automatique :** Reconnaissance du pays d'origine (facette F19) et extraction automatique du poids sur les codes à pesée variable (préfixes 20 à 29).
- **Référentiel EFSA officiel :** Affichage des codes paramètres officiels `RF-xxxx-PAR` et matrices FoodEx2.
- **Quotas bienveillants :** Dépassement autorisé pour ne jamais repartir les mains vides.
- **Fonctionnement 100% hors-ligne (PWA) :** Stockage local via IndexedDB et Service Worker.
